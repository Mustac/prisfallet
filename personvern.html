Hva vi samler inn

Prisfallet.no har ingen brukerkontoer og ber deg ikke om personopplysninger. Vi bruker ingen informasjonskapsler (cookies) for statistikk eller reklame på selve siden.

Besøksstatistikk: Vi bruker Cloudflare Web Analytics for å telle besøk og se hvilke sider som er populære. Verktøyet bruker ikke informasjonskapsler, lagrer ikke IP-adressen din og sporer deg ikke på tvers av nettsteder. Vi ser bare samlede tall.

Søk og klikk på siden: For å forbedre utvalget lagrer vi anonymt hva som søkes etter i søkefeltet, hvilke tilbud som åpnes og klikkes på, hvilken kategori og hvilke filtre som velges, hvilken nettside du kom fra, om du bruker mobil, nettbrett eller PC (ut fra skjermbredden), og land og fylke/region besøket kommer fra. Vi lagrer ikke IP-adresse, nettleserdata eller noe som kan knyttes til deg, og e-postadresser og telefonnumre som skrives i søkefeltet fjernes automatisk. Dataene lagres hos Cloudflare så lenge Prisfallet.no er i drift. Siden de ikke inneholder personopplysninger, kan de ikke knyttes til deg.

Samlet statistikk: Vi kan dele eller selge samlet, anonym statistikk til butikker og andre samarbeidspartnere, for eksempel hvilke produktkategorier og merker som er mest etterspurt. Slik statistikk viser bare totaler for mange besøk og kan aldri knyttes til deg.

  • Drift og sikkerhet: Siden leveres av Cloudflare. Cloudflare behandler tekniske data som IP-adresse og nettlesertype for å levere siden og beskytte den mot angrep. Les mer i Cloudflares personvernerklæring.
  • Bilder: Produktbilder lastes direkte fra butikkene eller affiliate-nettverkene, som da kan se IP-adressen din.
  • Skrifttyper: Siden laster skrifttyper fra Google Fonts, som kan se IP-adressen din.

Når du klikker på et tilbud

Lenkene til butikkene er annonselenker fra affiliate-nettverk (Adtraction, Awin, Daisycon, Kelkoo). Når du klikker, sendes du via nettverket til butikken, og nettverket og butikken kan sette informasjonskapsler for å registrere at kjøpet kom via Prisfallet.no. Dette styres av deres personvernerklæringer og samtykkeløsninger.
